ABOUT

서비스 안내

목적

제조현장 작업자가 설비 이상 발생 시 초기 확인 순서와 문제해결 방향을 빠르게 파악할 수 있도록 지원합니다.

기술 구조

HTML/CSS/JavaScript 프론트엔드에서 Python 기반 Vercel Serverless Function을 호출하고, 백엔드에서 AI API를 연동합니다.

주의사항

AI 분석 결과는 참고용입니다. 실제 작업에서는 해당 설비의 매뉴얼, 작업표준서, 안전절차와 사업장 규정을 우선 적용하세요.
